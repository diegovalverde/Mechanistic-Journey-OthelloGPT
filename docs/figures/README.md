# Figure Conventions

Use SVG for conceptual diagrams where possible. Use PNG only for plots, screenshots, or raster outputs when needed.

Every figure must have a descriptive filename and should be reproducible from code or clearly marked as illustrative. Figures derived from experiments should cite the notebook section that produced them. Avoid decorative stock imagery.
