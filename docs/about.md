# About

This project is a technical book and research memory system for a mechanistic journey through Othello-GPT.

The writing goal is to make the investigation understandable without flattening uncertainty. Chapters should separate intuition, mathematics, experiments, results, and open questions so future updates can revise claims cleanly.

The maintenance goal is equally important: every new experiment should first be recorded in the research log, then connected to figures, notebooks, and chapter prose.
